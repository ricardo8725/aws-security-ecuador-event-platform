Generar y enviar certificados

Solo se procesan los asistentes con check-in confirmado que aún no tienen certificado. El proceso envía el PDF por correo a cada asistente automáticamente.

Generando…

✓ Los certificados se almacenan en S3 privado y se sirven via CloudFront con URLs únicas por UUID.
✓ El campo cert_id y cert_url quedan guardados en DynamoDB por cada asistente.
✓ Si un asistente ya tiene certificado y se vuelve a ejecutar, no se regenera (idempotente).
⚠ El proceso puede tomar varios minutos para 400 asistentes (5 min de timeout en Lambda).
